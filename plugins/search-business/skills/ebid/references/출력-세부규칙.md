# 출력 세부규칙 — 계약 상세·첨부 다운로드

SKILL.md 에는 매번 필요한 규칙만 두고, **그 기능을 실제로 쓸 때만 필요한 세부**를 여기 모았다.
계약 검색에 `--detail` 을 붙일 때와 첨부를 실제로 받을 때 이 문서를 읽는다.

## 계약 상세(`--detail`) 규칙

- 건당 요청 1회가 추가된다. 기본 상한 30건(체결일 최신순) — 초과 시 stderr 경고가 나오니 답변에
  "상위 30건만 상세" 를 밝히고, 필요하면 기간을 좁히거나 `--detail-limit` 을 올린다.
- 상세가 주는 것: 계약기간·발주처·담당자와 부서 전화·계약업체 대표자/주소/지분율(공동도급이면 여러 행)·
  수의계약 근거 조문+사유·설계금액/예정가격/개찰일시/낙찰방법. 전자수의 건도 설계금액·예정가격이
  있다(전자 견적을 거침).
- 설계금액·예정가격이 비어 있으면 희망수량 등 입찰 정보가 없는 건이다. "정보 없음" 이 아니라
  **"입찰 정보가 없는 계약 유형"** 으로 쓴다.
- 담당자·대표자 연락처는 사이트가 공개한 값 그대로다. 요청받은 범위 밖으로 모아서 목록화하지 않는다.
- 표에 붙는 열: 사업자번호 대신 대표자·예정가격·계약기간·발주처·담당자·수의근거.

필드 하나하나의 의미와 실측 근거는 `ebid-필드사전.md` 의 「계약공개현황 API — 필드표」.

## 첨부 다운로드 결과 출력

`다운로드 결과`(`_받은목록.md`) 링크 한 줄 뒤에, 공고마다 제목 한 줄과 표 하나. 폴더 링크는
매니페스트 안에 있으니 답변에 또 쓰지 않는다.

```
202605940_[긴급]2026년 광주전남본부 CCTV 및 VMS 통합설치공사

| 파일 | 크기 | 상태 |
|---|---:|---|
| 공사입찰공고문.hwp | 260,608B | 성공 |
| 단가산출서.xlsx | 5,616,582B | 스킵 (이미 받음) |
| 시방서.hwpx | 4,446,265B | 실패 (server) |
```

- 상태는 **성공 / 스킵 / 실패** 셋. 실패는 괄호에 종류 코드(network·http·server·file)만 짧게 —
  자세한 사유는 `_받은목록.md` 에 있으니 답변에 길게 적지 않는다.
- 실패가 있으면 첫 줄에 `n개 중 m개 실패` 를 밝힌다.
