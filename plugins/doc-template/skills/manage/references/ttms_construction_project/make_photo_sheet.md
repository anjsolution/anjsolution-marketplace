# 현장 사진으로 사진대지 만들기 (ttms_construction_project/make_photo_sheet)

> **임시 위치 — TTMS 구축 전용 플러그인으로 이전 예정.** 이 폴더의 `README.md` 참고.

## 언제 쓰나
- 현장에서 찍은 사진 폴더를 받아 입고·납품·설치 사진대지를 만들 때
- 사용자가 사진마다 설명·순서를 주지 않았을 때 — 사진의 촬영 시각·위치와 내용으로 직접 묶고 설명을 단다

사진은 읽기만 한다. 양식 원본도 고치지 않는다.

## 쓰는 기능
| 단계 | 기능 | 상태 |
|---|---|---|
| 사진 분석 | `analyze_image` (`scripts/analyze-image.mjs -r --json`) | 제공 |
| 방문(시간대·위치)별 묶기 | `location_data_from_photos` (`photo-visits.mjs --json`) | 제공 |
| 사진 설명 만들기 | 사진을 직접 보고 설명 작성 — 사진이 많으면 가장 저렴한 모델의 서브에이전트에 맡긴다 | 제공 (전용 에이전트는 예정) |
| 양식 채우기·페이지 늘리기 | `hwpx` 스킬 (`pages` → `fill`/`export`) | 제공 |
| 관리동 등록·위치 검토·좌표/주소 채우기 | — | **제공 예정** |

## 절차

1. **사진 받기.** 폴더를 받는다. 카카오톡 압축본은 촬영 시각·GPS 가 없으니, 시간·장소별로 묶어야 하면 원본을 요청한다("원본으로 보내기" 또는 휴대폰에서 직접 복사).
2. **사진 분석.** `analyze-image.mjs <폴더> -r --json` — 장수, 촬영 시각·GPS 유무, 크기·용량을 본다.
   - 5MB 넘는 사진이 많으면 문서가 커진다고 알린다(압축은 이후 manage 기능 예정).
3. **묶기.**
   - GPS·시각이 있으면 `photo-visits.mjs <폴더> -r --json` 결과의 방문(시간대 + 위치)으로 묶는다. 사용자가 사진 정보를 주지 않아도 이 JSON 으로 직접 묶는다.
   - 시각만 있으면 촬영 시각순으로 놓고 시간 간격으로 나눈다.
   - 둘 다 없으면 파일 순서대로 두고, 순서를 사용자에게 확인한다.
4. **장소 확인.** 방문이 여러 곳이면 `location_data_from_photos` 절차대로 "○월 ○일 ○시, 사진 ○장 — 어느 관리동(장소)인가요?" 를 묻는다. 주소 변환은 사용자 동의 후에만.
5. **설명 만들기.** 사진 설명 칸(예: `내용-1`)이 있고 사용자가 설명을 주지 않았으면 사진을 보고 15자 안팎 명사형 설명을 단다.
   - 사진이 많으면 가장 저렴한 모델(예: Haiku)의 서브에이전트에 사진 목록을 넘겨 `{파일, 설명, 확신도, 중복 의심}` JSON 을 받는다.
   - 확신도가 낮거나 중복 의심인 사진만 사용자에게 확인받는다. 라벨에 다른 사업명·터널명이 보이면 반드시 알린다.
6. **양식 채우기.** `hwpx` 스킬로 진행한다.
   - `pages <서식>` 으로 반복할 사진 페이지 번호와 칸 수(예: 페이지당 사진 2장)를 확인한다.
   - 묶은 순서대로 페이지를 늘리는 값 JSON 을 만든다(공통 값: 공사명·위치·날짜, 페이지별: 사진·내용). 방문이 바뀌면 새 페이지에서 시작할지 사용자에게 묻는다.
   - 날짜 칸은 사용자가 준 날짜를 쓴다. 촬영 시각으로 채울 때는 먼저 확인받는다.
   - `fill`(hwpx) 또는 `export`(PDF) 후 결과 요약(값 없음·경고)을 전한다.
7. **관리동 위치 정보 정리 (제공 예정).** 아래는 아직 없는 기능이다. 요청이 오면 "제공 예정" 이라고 안내하고, 지금은 4단계의 방문 → 장소 표만 넘겨준다.
   - 관리동이 등록돼 있지 않으면 등록
   - 등록돼 있으면 위치 정보가 저장돼 있는지 확인하고, 사진 위치와 맞는지 검토해 수정 제안
   - 비어 있는 주소·위도·경도 채우기

## 주의
- **위치(GPS)는 민감 정보다.** 사용자가 요청하지 않으면 좌표를 사진대지·값 JSON 에 넣지 않는다. 사진대지의 `위치` 칸에는 사용자가 확인한 장소 이름을 쓴다.
- 장소·관리동 이름은 사용자가 답한 것만 쓴다. 좌표·주소만 보고 단정하지 않는다.
- 촬영 시각이 없는 사진의 날짜를 파일 이름으로 추측하지 않는다.
- 사진 순서·설명은 문서에 그대로 나가는 내용이다. 자동으로 정한 것은 넣기 전에 목록으로 보여 준다.
