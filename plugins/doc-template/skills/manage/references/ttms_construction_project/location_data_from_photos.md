# 현장 사진으로 방문 기록 정리 (ttms_construction_project/location_data_from_photos)

> **임시 위치 — TTMS 구축 전용 플러그인으로 이전 예정.** 지금은 doc-template 의 manage 스킬 안에 있다.
> 이전할 때는 `references/ttms_construction_project/` 와 `scripts/ttms_construction_project/` 폴더를 함께 옮기고, `photo-visits.mjs` 가 import 하는 `scripts/analyze-image.mjs` 도 같이 옮긴다.

## 언제 쓰나
- 구축 현장에서 찍은 사진으로 어느 날 어디(어느 설치 장소 — 관리동·지사·본부·○○청 서버실 등)에 다녀왔는지 정리하고 싶을 때
- 구축 전이라 비어 있는 설치 장소(관리동 등) 좌표를 채울 근거 자료가 필요할 때

사진은 읽기만 한다.

## 실행 방법
```bash
node "${CLAUDE_PLUGIN_ROOT}/skills/manage/scripts/ttms_construction_project/photo-visits.mjs" <경로> [<경로> ...] [--list <목록.txt>] [-r|--recursive] [--gap-min 60] [--radius-m 500] [--geocode kakao|vworld] [--json]
```
Codex 에서는 이 스킬 폴더 기준 상대 경로 `scripts/ttms_construction_project/photo-visits.mjs` 로 실행한다. Node 18 이상, 설치할 것 없음.

- 입력 규칙(`<경로>`, `--list`, `-r`)은 `analyze_image` 와 같다.
- 방문 묶기: GPS 와 촬영 시각이 둘 다 있는 사진만 대상으로, 촬영 순서대로 보다가 직전 사진과 `--gap-min` 분(기본 60)을 넘게 떨어지거나 현재 방문 중심에서 `--radius-m` 미터(기본 500)를 넘게 벗어나면 새 방문으로 나눈다. 방문 중심은 사진 좌표의 평균, 반경은 중심에서 가장 먼 사진까지의 거리다.
- 종료 코드: `0` 성공 / `1` 입력 경로가 전부 없음, 주소 변환 키 없음 / `2` 사용법 오류.

## 출력
```
방문 1 | 2026-09-17 10:12 ~ 11:40 | 사진 14장 | 반경 80m | 37.68301,128.71899 | (주소)
  파일명, 파일명, ...
```
끝에 `GPS 없음 a장, 시각 없음 b장, 둘 다 없음 c장` 과 `방문 N곳`. `--json` 은 `{ visits, no_gps, no_time, no_both, summary }` 를 낸다.

## 절차
1. 사진 폴더를 받는다. 카카오톡·메신저로 받은 압축본은 GPS·촬영 시각이 지워져 있으니, 필요하면 원본을 요청한다(휴대폰에서 직접 복사하거나 카카오톡 **"원본으로 보내기"**).
2. `photo-visits.mjs` 를 실행한다. 방문이 0곳이면 이유(GPS 없음·시각 없음 장수)를 설명하고 끝낸다.
3. 주소 변환(`--geocode`)은 기본으로 쓰지 않는다. 사용자에게 **"방문 중심 좌표를 카카오(또는 VWorld)로 보내도 되나요?"** 를 묻고 동의한 뒤에만 쓴다. 보내는 것은 방문 중심 좌표뿐이며 키는 환경변수(`KAKAO_REST_KEY` / `VWORLD_KEY`)로 받는다. 키가 없으면 안내하고 끝낸다. 키를 git·문서에 적지 않는다. 한 방문의 변환이 실패하면 그 방문의 주소만 비고 나머지는 계속된다.
4. 방문마다 장소를 묻는다. 한 번에 목록으로 보여 주고 답을 받는다.
   예: "9월 17일 10:12~11:40, 사진 14장(반경 80m), (주소) — 어느 설치 장소(터널 관리동, 지사·본부·○○청 서버실 등)에 다녀오셨나요?"
5. 결과 표를 만든다: 방문 / 시각 / 장소(사용자 답) / 중심 좌표 / 사진 수 / 확인 여부. 중심 좌표 열은 대화에서 보여 주기만 하고, 파일(CSV·JSON)로 저장하거나 문서에 넣는 것은 사용자가 요청할 때만 한다.
6. 설치 장소(관리동 등) 데이터(TMS·이관 JSON)에 넣는 일은 이 절차 밖이다. 표를 넘겨주고 끝낸다.

## 주의
- **위치(GPS)는 민감 정보다.** 사용자가 요청하지 않으면 좌표를 문서·값 JSON 에 넣지 않고, 다른 곳에 공유하자는 제안도 하지 않는다.
- 위치·시각이 없는 사진은 추측하지 않고 "없음"으로 보고한다. 파일 이름의 날짜는 촬영 시각이 아니다.
- 방문의 장소는 사용자가 답한 것만 적는다. 주소나 좌표만 보고 설치 장소 이름을 단정하지 않는다.
