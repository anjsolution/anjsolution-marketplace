# 사진대지 종류별 필요한 사진 (ttms_construction_project/photo_sheet_types)

> **임시 위치 — TTMS 구축 전용 플러그인으로 이전 예정.** 이 폴더의 `README.md` 참고.
> 업무 담당자의 설명(2026-10-02)을 기준으로 하고, 과거 사진대지 8건(2024~2025, 공장검수·입고·납품·설치)을 분석한 결과로 보강했다.

## 명칭

| 이 문서에서 쓰는 이름 | 현장에서 함께 쓰는 이름 |
|---|---|
| **서버 입고** 사진대지 | 공장검수 사진대지, 자재 입고 사진대지 (서버 입고 ≒ 공장검수) |
| **서버 납품** 사진대지 | 자재 납품 사진대지, 서버 설치 사진대지 |

- 지금은 **"서버 입고"** 라는 이름을 쓴다. 명칭을 바꿔야 한다면 바로 고치지 말고 저장소에 **이슈를 등록**해 달라고 안내한다(Issues → 개선 제안).
- 사용자가 다른 이름으로 말해도 위 표로 같은 종류를 찾는다.

## 서버 입고 사진대지

- **언제·어디서:** 서버가 회사에 들어왔을 때. 장소는 보통 **본사 사무실** 또는 **개발팀 사무실**.
- **식별 종이:** 사진 촬영용 서버 정보 종이(서버 납품 정보 — 사업·서버 식별용)를 출력해 **박스에 붙이거나 올려 두고** 함께 찍는다. 어떤 서버를 찍은 사진인지 알 수 있게 하기 위해서다.
- **필요한 사진 (보통 이 순서):**
  1. 개봉 전 박스 전체 (식별 종이가 보이게)
  2. 박스 개봉 과정 — 단계마다 한 장씩
  3. 박스 개봉 후 내부 상태
  4. 서버 측면의 **시리얼 번호**가 보이는 사진
- 서버가 여러 대(이중화 등)면 서버마다 위 사진을 찍고, 식별 종이로 어느 서버인지 구분한다.

## 서버 납품 사진대지

- **언제·어디서:** 현장에 서버를 가져가 설치할 때. 장소는 **특정 터널의 관리동**(서버가 설치되는 곳)이다. 사진대지의 위치 칸·방문 장소는 그 관리동 이름이 된다.
- **필요한 사진:**
  1. 현장에서 박스 풀기 전
  2. 박스 푼 뒤
  3. **서버랙 4장 (필수)** — 서버가 들어갈 랙을
     - 설치 **전** 전면 / 설치 **전** 후면
     - 설치 **후** 전면 / 설치 **후** 후면
  4. **H/W 정상 실행** — 1장 이상 (필수)
  5. **S/W 정상 실행** — 1장 이상 (필수)
- 랙 4장과 H/W·S/W 정상 실행 사진이 없으면 사진대지를 만들기 전에 사용자에게 빠졌다고 알린다.
- 과거 문서에서 함께 자주 나온 사진(선택): 현장 자재 검수(개봉), **서버랙 전원·네트워크 확인**, **설치 작업 완료 / 랙 전체 모습**.
- 과거 문서의 전형적인 순서: 자재 검수(개봉) → 설치 전 랙 전면·후면 → 전원·네트워크 확인 → 설치 → H/W·S/W 동작 확인(부팅·OS 화면) → 설치 후 랙 전면·후면 → 설치 완료.

## 과거 사진대지에서 확인한 것 (8건)

- **파일 이름·쪽 제목이 실제 내용과 자주 다르다.** "서버설치" 문서의 쪽 제목이 "자재납품", 설치 문서인데 "자재입고"로 남은 경우, `04. 인수` 폴더의 파일인데 내용은 설치 사진인 경우가 있었다. 종류는 이름보다 **사진 내용**으로 판단하고, 애매하면 사용자에게 묻는다.
- **공장검수(≒ 서버 입고):** 박스 전체 → 주 서버(Main) 박스 라벨 → 개봉한 서버 → 이중화 서버(Slave) 같은 순서. 서버가 2대면 서버마다 같은 사진을 찍고 Main/Slave 로 구분했다. 공장검수 양식은 위치·일자 칸 없이 품목·내용만 있다.
- **입고 문서의 설명**은 "TTMS 서버 입고 검수"처럼 한 문구로 뭉뚱그린 경우가 많았다 — 위 서버 입고 항목 이름으로 구체적으로 쓰는 것을 권한다.
- **양식 구조:** 모두 한 쪽에 사진 2칸(사진 위, 설명 표 아래). 표 머리는 위치·품목·내용·일자(공장검수는 품목·내용). 표지 표에 시리얼 번호(SN) 칸이 있는 양식과 없는 양식이 섞여 있다.
- 인수 단계만의 사진(시운전·인수 확인 등)은 이번 표본에 없었다.

## 사진대지를 만들 때 쓰는 법

- `make_photo_sheet` 절차에서 사진을 묶은 뒤, 종류별 **필수 사진이 다 있는지** 이 목록으로 확인하고 빠진 것을 질문에 넣는다.
- 사진 설명(내용 칸)은 위 항목 이름을 기준으로 쓴다(예: "개봉 전 박스 전체", "서버 시리얼 번호", "설치 전 랙 전면", "S/W 정상 실행").
- 순서를 사용자가 주지 않았으면 위 순서대로 놓는다.
