# 토큰 규칙

- 형태 `{{필드명}}`. 정규식 `/\{\{\s*([^{}\s][^{}]*?)\s*\}\}/g`. 안쪽 공백은 허용하고 중첩은 안 된다.
- 대상은 `Contents/section*.xml` 전부(본문·머리말·꼬리말).
- 같은 필드를 여러 곳에 써도 된다. 모두 같은 값으로 채워진다.
- 토큰은 한글에서 사람이 직접 타이핑한다(자동 토큰화 없음).
- 한글이 토큰을 여러 run 으로 쪼개면 `scan` 이 `broken`(쪼개진 토큰)으로 보고한다. 조용히 넘어가지 않는다.
- 조판 캐시(`<hp:linesegarray>`)는 문서 전체에서 지운다(채운 문단만이 아님). 지우지 않으면 한글이 글자를 겹쳐 찍는다(실측).
- 값이 없는 토큰은 남기지 않고 **빈칸으로 지운다.** 지운 키는 결과 요약의 `값 없음` 목록에 나온다.
- 값 JSON 에 있으나 양식에 없는 키는 `서식에 없는 키` 로 보고한다.
- 값 조회는 값 JSON 자신의 키만 본다(상속된 속성은 무시).
- 키에 `사진` 또는 `이미지` 가 들어가면 이미지 자리다. 규칙은 `images.md`.

## 서식 작성 팁
- 토큰은 한글에서 **한 번에 이어서 타이핑**한다. 중간에 글자 서식(굵게·색·크기)을 바꾸거나 붙여넣기를 섞으면 토큰이 쪼개진다.
- 한 토큰 안에서는 서식을 바꾸지 않는다. 서식은 토큰 전체를 선택해 한 번에 준다.
- 서식을 편집한 뒤에는 `scan` 으로 `broken` 이 비었는지, 기대한 토큰이 모두 잡히는지 확인한다.
- 사진 설명 칸에 쓸 값이 파일명 확장자(`.jpg` 등)로 끝나면 이미지로 오인된다. 캡션에 확장자 문자열을 넣지 않는다.
